How should my data be set up?

One row per participant, with each measurement or grouping variable as its own column.

Example — comparing body mass between genders
IDGenderBodymassAge
1171.127.0
2262.324.4
3185.656.9
4253.722.1

Use numeric codes (e.g. 1/2) or text labels (Male/Female) for groups — both work.

DO
  • Put column headers in row 1.
  • Keep one row per participant, even with repeated measures.
  • For paired data (pre/post), use two columns (e.g. Score_pre, Score_post).
  • Leave cells blank for missing values — don\'t use 999 or "N/A".
AVOID
  • Splitting groups into separate columns (e.g. Bodymass_male + Bodymass_female) — keep them in one column with a grouping column alongside.
  • Multiple header rows or merged cells.
  • Spaces or special characters in column headers (use Body_mass not Body mass (kg)).

How big do you expect the effect to be?

Effect size is how strong the difference or relationship is. Without prior research to go on, medium (0.5) is the standard recommended default.

Expected effect size
0.50

Cohen's d = 0.50 · Medium effect is the default when no prior estimate is available (Cohen, 1988).

Step three

Confidence and power

These control how certain you want to be. Most journals expect alpha = 0.05 and power = 0.80. Leave these unless your supervisor says otherwise.

0.05

Chance of a false positive — saying something works when it doesn't. 0.05 = 5% risk, the standard.

0.80

Chance of detecting a real effect if one exists. 0.80 (80%) is the journal minimum.
